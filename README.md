## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-rendered `entry.png` beside it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The page itself is drawn by `render.py` (Pillow, build time only) from facts checked against reporting dated 17 November 2026.
